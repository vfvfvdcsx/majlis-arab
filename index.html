شو هو المفتاح؟ مثل بطاقة تخلّي هالموقع يستخدم الذكاء الاصطناعي. تسويه مرة وحدة بس، وتختار وحدة من الطريقتين:

الطريقة المجانية: مفتاح جيميناي من جوجل (بدون بطاقة)

  1. افتح موقع aistudio.google.com وسجّل دخول بحساب جوجل حقك.
  2. اضغط Get API key (يعني: خذ مفتاح)، وبعدين Create API key (يعني: سوّ مفتاح).
  3. انسخ المفتاح. يبدأ بـ AIza.
  4. الصقه في المربع اللي فوق واضغط «احفظ».

جيميناي المجاني له حد بالدقيقة وباليوم. إذا وصلته، المجلس ينتظر شوي ويكمل بروحه. جوجل ممكن تستخدم كلام النسخة المجانية لتحسين خدماتها، فلا تكتب فيه شي سري.

الطريقة المدفوعة: مفتاح Claude (أفضل جودة)

  1. افتح موقع console.anthropic.com وسجّل دخول.
  2. من Billing (الدفع) اشحن رصيد، 5 دولار تكفي وايد.
  3. من API Keys (المفاتيح) اضغط Create Key، وانسخ المفتاح. يبدأ بـ sk-ant-.
  4. الصقه في المربع اللي فوق واضغط «احفظ».

المفتاح ينحفظ في متصفحك أنت بس. اللي تشارك معه الرابط يحتاج يحط مفتاحه هو، وما يشوف مفتاحك ولا مواضيعك.

أمثلة:

اضغط «تكلّم» وقول طلبك بلهجتك، أو اكتبه. «ابدأ الموضوع» يشغّل الفريق بمفتاحك (جيميناي المجاني أو Claude)، والعرض التجريبي ما يستخدم شي.
